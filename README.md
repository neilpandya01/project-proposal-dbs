# Wingmates — Project Proposal

A free social app for avgeeks: log the flights you take and the planes you spot,
follow friends live on the map, and share aviation news. Works on any phone.

- [`index.html`](index.html) — the proposal page (static, deploys to Vercel as-is)
- [`PLAN.md`](PLAN.md) — full plan: problem, user research, features, data sources, roadmap
